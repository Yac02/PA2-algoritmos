## 2. Descripción y objetivo

**Problema:**  
Una organización requiere gestionar una secuencia dinámica de solicitudes de atención. El registro cambia constantemente con nuevos casos, eliminaciones y reubicaciones, requiriendo en ciertos procesos la navegación en ambos sentidos o mantener un ciclo continuo de revisión.

**Objetivo:**  
Aplicar estructuras lineales dinámicas (listas enlazadas simples, dobles y circulares) para resolver el caso propuesto. Se busca modelar correctamente las estructuras, diseñar algoritmos de inserción, búsqueda, modificación y eliminación, y justificar la eficiencia y elección de cada alternativa.
